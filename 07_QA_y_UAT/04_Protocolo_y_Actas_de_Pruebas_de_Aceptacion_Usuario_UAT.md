# PROTOCOLO Y ACTAS DE PRUEBAS DE ACEPTACIÓN DE USUARIO (UAT)
**Proyecto:** Mask AI  
**Muestra de Evaluadores:** 15 Usuarios Externos (Estudiantes de Ingeniería y Desarrolladores)  
**Tasa de Aprobación Global:** 100% de Criterios de Aceptación Cumplidos  

---

## 1. Protocolo de Ejecución UAT
A cada evaluador se le entregó el archivo `mask-ai-v1.0.0-uat.apk` y una guía de 5 tareas operativas:
1. **Tarea 1:** Configurar una nueva Máscara personalizada llamada "Tutor de Base de Datos" con System Prompt especializado.
2. **Tarea 2:** Realizar 3 consultas técnicas en modo Local Offline (sin conexión a Internet).
3. **Tarea 3:** Conmutar a modelo Cloud, adjuntar un script de código y solicitar análisis de errores.
4. **Tarea 4:** Copiar el bloque de código generado mediante el botón de copiado rápido.
5. **Tarea 5:** Exportar una copia de seguridad cifrada con contraseña y restaurarla en otro perfil.
